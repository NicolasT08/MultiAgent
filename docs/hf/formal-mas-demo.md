# Formal-MAS: recorded runs

A team of AI agents (Planner, Retriever, Generator, Autoformalizer, Critic) solves
olympiad-style mathematics problems, and the **Lean 4 kernel** decides whether each proof is
correct: a problem counts as solved only if the proof compiles, contains no `sorry`, and
`#print axioms` reports only `propext`, `Classical.choice` and `Quot.sound`.

This Space is a static page (Spanish/English) that plays back five runs recorded during the
study, step by step, plus the study's results on the 30 `test` problems. It runs no model and
no Lean, and needs no key. The live version runs locally with Lean and DeepSeek; see the code
repository.

- Code (installation, live demo, reproduction): https://huggingface.co/NicolasT08/formal-mas
- Evaluation set, curation files, results and run logs: https://huggingface.co/datasets/NicolasT08/formal-mas-eval
- Retrieval index over Mathlib: https://huggingface.co/datasets/NicolasT08/formal-mas-index

Final project of the Artificial Intelligence course, UPTC Sogamoso. The page is generated by
`scripts/build_space.py` of the code repository from `demo/replays/` and
`docs/results/results.md`; its only external dependency is KaTeX 0.16.11 (MIT) from jsDelivr.
